# NFC Leads — поиск клиентов для продажи NFC-стендов (Android APK)

Приложение ищет заведения Краснодара через официальный API 2ГИС, убирает дубли,
выделяет заведения с малым числом отзывов / низким рейтингом, ведёт статусы и
комментарии, экспортирует базу в Excel.

## 1. Ключ 2ГИС (бесплатно)
1. Зарегистрируйтесь на https://dev.2gis.com
2. Создайте ключ для «Places API» (демо-ключ даёт ограниченное число запросов).
3. Вставьте ключ в приложении на вкладке «Поиск».

## 2. Как получить APK (без установки чего-либо на ПК)
1. Создайте аккаунт на https://github.com и новый репозиторий (Private).
2. Загрузите ВСЕ файлы этой папки (включая скрытую папку `.github`).
3. Откройте вкладку Actions → «Build APK» → дождитесь зелёной галочки (15–30 мин).
4. Внутри завершённого запуска скачайте артефакт `nfc-leads-apk` — это ZIP с файлом .apk.
5. Перенесите .apk на телефон и установите (разрешите «установку из неизвестных источников»).

## 3. Использование
- «Поиск»: выберите категории, район или введите адрес (ищет в радиусе), нажмите «Старт».
  «Пауза» останавливает поиск, «Старт» продолжает с того же места.
  «Поиск новых» перезапускает выбранные категории и добавляет только новые заведения.
- «База клиентов»: фильтры по статусу, «Мало отзывов», «Низкий рейтинг», «Не звонили».
  Нажмите на заведение — статус, отметка «звонили», комментарий, кнопки «Позвонить», карты, сайт.
- «Excel (.xlsx)»: файл сохраняется в папку «Загрузки» телефона.

## Ограничения
- Рейтинг и число отзывов отдаёт 2ГИС (если разрешено вашим ключом). Яндекс Карты —
  это ссылка-поиск по названию и адресу (официальный API организаций Яндекса платный).
- Телефон/сайт есть не у всех заведений.
